# Contributing

Contributions that improve instructional clarity, technical accuracy, accessibility, platform compatibility, or safe laboratory practice are welcome.

Before submitting a pull request, open an issue describing the proposed change. Test commands in an isolated laboratory environment, identify required privileges and supported platforms, and explain expected outputs. Never include active credentials, real targets, personal data, or instructions that encourage testing systems without authorization.

Pull requests should be focused, document validation performed, and preserve the distinction between defensive education and unauthorized activity. Security-sensitive concerns should follow [SECURITY.md](SECURITY.md), not a public issue.
